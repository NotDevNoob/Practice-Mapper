# Practice Mapper

Practice Mapper is a shortcut for practice copies.

Instead of searching for a StartPos or practice version yourself, the mod can open the approved one for you from the level page.

## What You See

- A small `Practice` button next to the difficulty when that level already has an approved mapping
- A `Pick Practice` flow when the level does not have one yet
- A `Use This Level` button after you open the level you want to submit

## What Happens

1. You open an online level.
2. If that level has an approved practice copy, press `Practice`.
3. The mod opens the mapped level for you.
4. If there is no mapping yet, you can pick one in-game and send it for review.

## Why It Exists

- faster practice access
- less searching
- easier community submissions
- safer behavior when a mapping is broken or invalid

If a mapping is missing or wrong, the mod will not intentionally send you to some random fallback level.
